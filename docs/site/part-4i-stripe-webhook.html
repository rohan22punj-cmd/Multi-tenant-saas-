Stripe Webhook PLANNED

This feature is designed but not yet built in the repository. It will handle real-time plan lifecycle events from Stripe.

Architecture

The webhook endpoint will require the raw request body for signature verification. This is achieved via express.raw({ type: 'application/json' })} middleware, preventing downstream JSON parsing that could break signature checks.

// Planned implementation
const sig = req.headers['stripe-signature'];
const event = stripe.webhooks.constructEvent(
  req.body, // raw Buffer
  sig,
  process.env.STRIPE_WEBHOOK_SECRET
);

Idempotency

To prevent duplicate processing of the same event, we will use a Redis claim pattern: SET key NX EX to atomically claim the event ID, releasing it on error. A fallback StripeEvent collection with a unique index on eventId provides persistence.
